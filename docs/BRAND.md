# Dolphi identity

**Dolphi** is the product name. The compact wordmark uses **DOLPHI** with an
original abstract dolphin head in profile: a rounded forehead, narrow beak,
angular eye and a friendlier curved negative-space smile. The mark was designed as native SVG
artwork and remains usable as a single color on a transparent background.

## Assets

- [Icon SVG](assets/dolphi-icon.svg) and [transparent PNG](assets/dolphi-icon.png).
- [Orange lockup SVG](assets/dolphi-lockup.svg) and [transparent PNG](assets/dolphi-lockup.png).
- [Light-background lockup SVG](assets/dolphi-lockup-dark.svg) and [transparent PNG](assets/dolphi-lockup-dark.png).
- [Repository banner SVG](assets/dolphi-banner.svg) and [PNG](assets/dolphi-banner.png).

Use the approved **version 3** silhouette with its refined upward smile.
The primary logo and theme color is **orange `#FF5F1F`** on both dark and light
backgrounds: RGB `255, 95, 31`; HSL `17, 100%, 56%`; OKLCH `0.69, 0.21, 39`.
The [theme definition](assets/dolphi-theme.json) records these supplied values.
Hex is the canonical rendering value.
Keep clear space around the head and wordmark. Use the icon for small avatars;
keep the transparent cutouts intact. The wordmark uses drawn paths, so rendering
does not depend on fonts installed on the viewer's computer.

The repository is `cogniolab/dolphi`; the Rust crate and Python package are
`dolphi`, the executable is `dolphi-server`, and the MCP command is `dolphi-mcp`.
The tagline remains: **Give your agents memory, keep control of your data.**

This replaces the prepublication MimiDB identity. Earlier snapshot envelope
identifiers and signed native-package version identifiers are retained for
compatibility and provenance. They do not change the public product name.

The layout uses the familiar compact animal-mark-and-wordmark convention. The
artwork is original; it does not reuse Turso's bull illustration or wordmark.
