# Community and Pro

Community is MIT-licensed source that you can run and modify. Dependencies
retain their own licenses; see [notices](../THIRD_PARTY_NOTICES.md).

## Community includes

- Identity-scoped memory and owner-reviewed shared proposals.
- Authentication, expiry, agent/credential revocation and logical quotas.
- Encrypted storage and independently encrypted backup/restore.
- Durable retries, audit history and verified backend migration.
- HTTP, Python SDK, agent-only MCP, examples and operational backup helpers.
- Tests, build provenance and self-hosting documentation.

Basic safety controls are Community features and are not withheld to force an
upgrade to a paid service.

## Planned Pro direction

The proposed managed offering focuses on hosting, operations, organization
administration, observability and support. Features should be proven before
being advertised as available. No Pro service, pricing, availability date,
support SLA or implemented SSO capability is announced in this alpha.

The [roadmap](../ROADMAP.md) separates shipped capabilities from future work.
Community's original source remains under the [MIT license](../LICENSE).
