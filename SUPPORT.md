# Support

Dolphi Community provides public documentation and community issue triage.
It does not include a response SLA or paid support contract.

## Getting help

Start with the [quick start](docs/QUICKSTART.md), [documentation index](docs/README.md)
and [limits](docs/LIMITS.md). Use the repository's bug template for reproducible
problems and its proposal template for new behavior. Include your exact commit,
storage profile, OS/architecture and a minimal synthetic example.

Never attach real databases, private logs, credentials or customer data. For
vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Maintainer contact

Dolphi is maintained by [Cognio Lab](https://github.com/cogniolab). For private
maintainer or conduct concerns, email [dev@cogniolab.com](mailto:dev@cogniolab.com).
The same monitored address receives private security reports under
[SECURITY.md](SECURITY.md). Public bugs and non-sensitive questions belong in
[cogniolab/dolphi issues](https://github.com/cogniolab/dolphi/issues).

No hosted chat community or paid support service is advertised as active.
